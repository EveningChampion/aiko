## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Privacy First** | All transcription happens locally on your Mac — zero cloud, zero tracking |
| **Whisper Powered** | Leverages OpenAI's state-of-the-art speech recognition model |
| **Multiple Formats** | Export transcripts as plain text, SRT subtitles, or structured JSON |
| **Fast & Accurate** | Handles accents, technical vocabulary, and long recordings with ease |
